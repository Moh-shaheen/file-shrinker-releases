# File Shrinker

A free desktop app for **Windows** and **macOS** that reduces PDFs and images to a size you choose,
without visible quality loss. Everything happens on your computer; nothing is uploaded.

## Download

Go to **[Releases](https://github.com/Moh-shaheen/file-shrinker-releases/releases/latest)** and pick the file for your computer:

| File | For |
|---|---|
| `File.Shrinker-x.y.z-arm64.dmg` | Macs with Apple chips (M1, M2, M3, M4…) |
| `File.Shrinker-x.y.z.dmg` | Older Macs with Intel chips |
| `File.Shrinker.Setup.x.y.z.exe` | Windows 10 / 11 |

Not sure which Mac you have? Open  menu → **About This Mac** and look at "Chip".

## Install

**Mac:** open the `.dmg`, drag **File Shrinker** into **Applications**. The first time, if macOS blocks it,
go to **System Settings → Privacy & Security** and click **Open Anyway**.

**Windows:** run the `.exe`. If you see "Windows protected your PC", click **More info → Run anyway**.

## Updates

The app tells you when a new version is available. Click **Download** in the banner and install it
the same way; your settings are kept.

## Supported files

PDF, JPG/JPEG, PNG, SVG, WEBP, GIF (incl. animated), AVIF, HEIC, TIFF, BMP.
